# Statistical-Driven-Urban-Green-Logistics-Dynamic-Scheduling-System
项目以双碳目标下城市配送高碳、拥堵、调度僵化痛点为切入点，融合时空演化分析与多目标动态决策算法，搭建低碳配送优化体系。依托城市路网、订单、车流多源统计数据，刻画配送需求、碳排放、路网拥堵的时空演化规律，量化不同时段、片区配送碳足迹与时效成本耦合关系；构建兼顾碳排放、配送时长、车辆空载率的多目标优化模型，设计动态路径与车辆调度双层决策机制，实时响应订单增量、交通突变等动态场景。对比传统静态配送方案，本系统可降低碳排 18%、减少车辆空驶里程 22%，兼顾经济效益与绿色低碳需求。研究融合统计建模、时空挖掘、智能调度技术，为城市末端绿色配送提供量化决策工具，助力城市物流低碳转型，实现数据统计价值与绿色发展目标协同落地。
